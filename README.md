# 모닝 노트

매일 아침 시장을 정리하고, 내 관점과 검증 가능한 예측을 기록해 두는 저장소입니다.

## 폴더 구조

```
모닝노트/
├─ README.md        이 문서
├─ 템플릿.md        노트 양식
└─ 노트/
   └─ 2026-09/
      └─ 2026-09-24.md
```

## 역할 구분

| 섹션 | 작성자 | 내용 |
|---|---|---|
| 1~7 | AI 자동 작성 | 시장 수치, 지표, 일정, 관찰 포인트, 채점할 지난 예측 목록 |
| 8 내 관점 | 본인 | 무엇이 중요하고 왜 그런가 |
| 9 오늘의 예측 | 본인 | 확인 가능한 예측과 확인일. **작성 당일 이후 수정하지 않습니다.** |
| 10 사후 채점 | 본인 | 확인일이 지난 예측의 결과와 원인 분석 |

## 매일 할 일

1. 평일 07:12(KST)에 클라우드의 AI가 그날 노트(1~7)를 만들어 `[자동]` 커밋으로 GitHub에 바로 올립니다. PC가 꺼져 있어도 실행됩니다.
2. GitHub Desktop에서 **Fetch origin → Pull origin**으로 새 노트를 받아옵니다. (받기 전에 편집하면 충돌할 수 있습니다.)
3. 노트를 읽고 8(내 관점)과 9(오늘의 예측)을 씁니다.
4. 7번 목록에 채점할 예측이 있으면, 원래 노트의 10번에 결과를 적습니다.
5. 본인 이름으로 커밋하고 **Push origin**을 누릅니다.

## 기록 원칙

- 틀린 예측도 지우지 않습니다.
- 9번은 작성 당일 이후 고치지 않습니다. 생각이 바뀌면 다음 날 새 예측으로 씁니다.
- 수치는 AI가 여러 출처로 교차 확인하지만 오류가 있을 수 있습니다. 중요한 수치는 원문 링크로 확인합니다.
- 유료 리포트 원문은 옮기지 않고 출처만 적습니다.

## 커밋 작성자 구분

- AI 자동 커밋: 작성자 `모닝노트 자동생성`, 메시지 앞에 `[자동]`. GitHub 계정 이메일과 다른 주소를 쓰므로 GitHub 활동 달력(잔디)에 집계되지 않습니다.
- 본인 커밋: GitHub Desktop 등에서 본인 계정으로 커밋합니다. 활동 달력에는 본인이 쓴 기록만 쌓입니다.

## 자동 실행

- Anthropic 클라우드 루틴 `모닝 노트 자동 생성`이 평일 07:12(KST)에 실행됩니다(cron `12 22 * * 0-4`, UTC). 관리: https://claude.ai/code/routines
- AI가 쓴 1~7절은 검토 전에 공개 저장소에 올라갑니다(사용자 동의, 2026-09-25).
- 그날 노트 파일이 이미 있으면 덮어쓰지 않고 멈춥니다. 이전 노트는 수정하지 않습니다.
